# PoE Craft Helper

Помощник крафта для **Path of Exile 1**: оверлей поверх игры и «мастерская» с функциями в духе Craft of Exile.
Копируешь предмет в игре (Ctrl+Alt+C), программа говорит следующий шаг и шанс успеха.
В игре ничего не нажимает — только читает буфер обмена, поэтому правил GGG не нарушает.

## Возможности
- **Стартовое окно (хаб)**: плитки «Мастерская / Мои крафты / Импорт кода / Настройки», активная цель, недавние предметы, библиотека крафтов с поиском; уведомление о новой версии.
- **Оверлей-карточка**: совет по предмету из буфера (английский и русский клиент) — заголовок по редкости, префиксы/суффиксы со свободными слотами, следующий шаг с шансом; по желанию рядом с курсором и с автоскрытием, как прайс-чек в APT.
- **Мастерская** (поверх игры):
  - пул модов любой базы: тиры, веса, шансы; влияния (Shaper/Elder/завоеватели), кластеры, катализаторы;
  - калькулятор: Alt+Aug, Alt→Aug→Regal, Chaos, эссенции, фоссилы, Harvest — шанс и средняя стоимость по ценам poe.ninja;
  - эмулятор: вся основная валюта, эссенции, фоссилы (вкл. особые), верстак и метакрафты, влияния, Awakener/Maven, Eldritch, Harvest, Veiled, звериные крафты, Vaal и Tainted, катализаторы, Hinekora's Lock; блокировка модов правым кликом;
  - сокеты: Chromatic и рецепты верстака (формула калькулятора Siveran);
  - настройки: горячие клавиши, язык интерфейса и клиента, обновления.
- **Иконки как на Craft of Exile**: валюта, эссенции, фоссилы, влияния и Eldritch в эмуляторе, таблицах, калькуляторе и оверлее; полоски веса модов в пуле. Картинки скачиваются с CDN игры при первом запуске (`data/icons`).
- **Стартовый набор** из 13 крафтов в `goals/`.

## Запуск из исходников
```
pip install -r requirements.txt
python overlay.py
```
Данные модов (RePoE) скачаются при первом запуске. Тесты: `pip install -r requirements-dev.txt && python -m pytest -q`.

## Сборка и релизы
`.github/workflows/build.yml` на `windows-latest`: скачивает данные, гоняет тесты, собирает `PoECraftHelper.exe`,
проверяет, что он запускается, и пакует архив. Тег `v*` (например `git tag v0.11.0 && git push --tags`) создаёт
релиз с архивом. Кнопка «Проверить обновления» в программе смотрит последний релиз репозитория,
указанного в настройках (или `DEFAULT_REPO` в `poecraft/updater.py`).

## Устройство
| Файл | Что делает |
|---|---|
| `overlay.py` | оверлей, буфер обмена, горячие клавиши, точка входа exe |
| `mainwin.py` | мастерская: пул, калькулятор, эссенции/фоссилы, эмулятор, сокеты, настройки |
| `editor.py` | редактор крафтов |
| `poecraft/data.py` | загрузка RePoE (англ. + рус.) |
| `poecraft/parser.py` | разбор Ctrl+Alt+C (англ. и рус.) |
| `poecraft/pool.py`, `calc.py` | пул модов, точные шансы и симуляции |
| `poecraft/advisor.py` | советчик для оверлея |
| `poecraft/currency_craft.py`, `harvest.py`, `influence.py`, `sockets.py` | эссенции/фоссилы, Harvest/Veiled, влияния/Eldritch, сокеты/катализаторы |
| `poecraft/emulator.py` | эмулятор крафта |
| `poecraft/prices.py` | цены poe.ninja |
| `poecraft/hotkeys.py`, `i18n.py`, `updater.py` | горячие клавиши, перевод, обновления |

Данные: RePoE (https://repoe-fork.github.io), содержимое принадлежит Grinding Gear Games.
Программа не связана с GGG и не одобрена ими.
