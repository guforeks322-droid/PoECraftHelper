# PoE Craft Helper

**Помощник крафта для Path of Exile 1** — оверлей поверх игры и мастерская для расчёта и проб крафта прямо на рабочем столе, без браузера.

Скопировал предмет в игре — программа показывает, каких модов не хватает, **следующий шаг** и шанс успеха. В мастерской — пул модов, калькулятор цены крафта по ценам poe.ninja и эмулятор, где можно потратить виртуальную валюту, прежде чем тратить настоящую.

> 🇬🇧 *Path of Exile 1 crafting helper: an in-game overlay with next-step advice plus a desktop workshop (mod pool, cost calculator, full crafting emulator). Russian and English game clients.*

---

## Возможности

### Оверлей поверх игры
- Наведи курсор на предмет и нажми **Ctrl+Alt+C** — появится карточка: моды по префиксам и суффиксам, тир, качество ролла, свободные слоты.
- **Следующий шаг** с иконкой валюты, шансом и средним числом попыток: Exalt, верстак, эссенция…
- Может появляться рядом с курсором, и сам прятаться через N секунд.
- Понимает **английский и русский** клиент игры.

### Стартовое окно (хаб)
- Плитки «Мастерская», «Мои крафты», «Импорт кода», «Настройки».
- Активная цель, недавние предметы с прогрессом (2/3 нужных мода).
- Библиотека крафтов с поиском и фильтром по классу предметов.

### Мастерская
| Вкладка | Что умеет |
|---|---|
| **Пул модов** | Все префиксы и суффиксы базы: тиры, веса, % выпадения, полоски весов. Влияния (Shaper, Elder, завоеватели), кластеры, катализаторы. **Правый клик — заблокировать мод.** |
| **Калькулятор** | Alt+Aug, Alt→Regal, Chaos, эссенции, фоссилы, Harvest — шанс и **средняя цена** в chaos/div по ценам poe.ninja. Самый дешёвый метод выделен. |
| **Эссенции и фоссилы** | Выбор иконками и наглядный сдвиг шансов: «было → стало», какие моды стали чаще, реже, какие пропали. |
| **Эмулятор** | Карточка предмета как в игре, качество роллов, журнал «что добавилось / убралось», откат к любому шагу. Подробнее ниже. |
| **Сокеты** | Chromatic и рецепты верстака по формуле калькулятора Siveran, с белыми сокетами 3.29. |

### Эмулятор крафта
- **Валюта:** Transmutation, Alteration, Augmentation, Regal, Alchemy, Chaos, Exalted, Annulment, Scouring, Divine.
- **Эссенции**, все **фоссилы**, в том числе особые: Fractured, Glyphic, Tangled, Sanctified, Bloodstained, Hollow, Gilded.
- **Верстак** и метакрафты: Prefixes/Suffixes Cannot Be Changed, Cannot roll Attack/Caster, Can have up to 3 Crafted.
- **Влияние:** Exalt'ы завоевателей, Awakener's Orb, Orb of Dominance (Maven), Craicic Maw.
- **Eldritch:** Ember, Ichor, Eldritch Chaos/Exalt/Annul, Orb of Conflict.
- **Harvest** reforge, **Veiled** Chaos/Exalt и выбор у Jun.
- **Звериные крафты:** Farric Wolf/Lynx Alpha, Split, отпечаток (Craicic Chimeral), аспекты.
- **Vaal Orb** и **Tainted**-валюта, **катализаторы** с качеством, **Hinekora's Lock** (предпросмотр результата).
- Выбрал метод → клик по предмету. **«Крутить до цели»** — автоспам до нужных модов. **«Прогнать N предметов»** — среднее, медиана и 90% попыток и цена за предмет.
- **Ctrl+Shift+E** — предмет под курсором в игре сразу попадает в эмулятор со своими модами и значениями.

### Крафты и обмен
- Крафт-цель — это набор нужных модов с худшим допустимым тиром. В комплекте 13 стартовых крафтов.
- Код крафта вида `PCH1:…` — вставь его в Discord или Telegram, другой игрок нажмёт «Импорт кода».

### Удобства
- Окна без системной рамки, в одном тёмно-золотом стиле, поверх игры.
- Глобальные горячие клавиши настраиваются, интерфейс на русском или английском.
- Иконки валюты и картинки предметов качаются с CDN игры при первом запуске, дальше всё работает офлайн.
- Проверка обновлений через релизы GitHub.

## Установка

1. Скачай `PoECraftHelper-vX.Y-win64.zip` из [Releases](../../releases).
2. Распакуй **целиком**: `PoECraftHelper.exe` должен лежать рядом с папками `data` и `goals`.
3. Включи в игре режим окна **«Оконный без рамки» (Windowed Fullscreen)**, иначе Windows не покажет окна поверх игры.
4. Запусти `PoECraftHelper.exe`.

Подробная инструкция — `Как пользоваться.txt` в архиве.

### Горячие клавиши по умолчанию
| Сочетание | Действие |
|---|---|
| `Ctrl+Alt+C` (игра) | скопировать предмет → совет в оверлее |
| `Ctrl+Shift+E` | предмет под курсором → в эмулятор |
| `Ctrl+Shift+O` | показать/спрятать оверлей |
| `Ctrl+Shift+M` | показать/спрятать мастерскую |
| `Ctrl+Shift+H` | показать/спрятать хаб |

---

## Безопасно ли это?

Программа **читает буфер обмена** и ничего не делает в игре сама. Единственное исключение — `Ctrl+Shift+E`: одно нажатие копирования на одно твоё нажатие. Эту опцию можно выключить в настройках. Программа не читает память игры и не трогает её файлы.

## Запуск из исходников

```bash
pip install -r requirements.txt
python overlay.py
```

Данные модов (RePoE) скачаются при первом запуске.

Тесты:
```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

## Сборка и релизы

`.github/workflows/build.yml` на `windows-latest`: скачивает данные, гоняет тесты, собирает `PoECraftHelper.exe` (PyInstaller), проверяет запуск и пакует архив. Тег `v*` создаёт релиз:

```bash
git tag v0.21.0 && git push --tags
```

Чтобы кнопка «Обновить» работала, укажи репозиторий в «Настройки → Обновления» (формат `владелец/название`) или в `DEFAULT_REPO` в `poecraft/updater.py`.

| `poecraft/currency_craft.py`, `harvest.py`, `influence.py`, `sockets.py` | эссенции, фоссилы, Harvest, Veiled, влияния, Eldritch, сокеты, катализаторы |
| `poecraft/prices.py`, `icons.py` | цены и иконки poe.ninja |
| `poecraft/hotkeys.py`, `i18n.py`, `updater.py`, `recipes.py` | горячие клавиши, перевод, обновления, коды крафтов |
